# AWS Cloud & DevOps Labs

Welcome to my hands-on AWS Cloud and DevOps learning repository.

This repository documents practical implementations of AWS services, cloud infrastructure, networking, security, automation, and DevOps fundamentals.

## Areas of Focus

- AWS Cloud Infrastructure
- EC2 and EBS
- VPC and Network Configuration
- IAM and Cloud Security
- S3, Lambda and CloudFront
- Auto Scaling and High Availability
- AWS CloudFormation
- Linux Administration
- DevOps Fundamentals
